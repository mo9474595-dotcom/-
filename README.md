# نظام الامتحانات الآمن (Exam System)

منصة امتحانات إلكترونية باللغة العربية (Next.js + PostgreSQL) مع لوحة تحكم كاملة
للأستاذ وعدة طبقات حماية من الغش أثناء الامتحان.

## الميزات

**للطالب:**
- الدخول برمز امتحان فريد يُصدره الأستاذ لكل طالب (لا يوجد تسجيل حساب).
- قفل شاشة كامل إلزامي (Fullscreen API) قبل بدء الامتحان.
- رصد وتسجيل: مغادرة التبويب/الصفحة، فقدان تركيز النافذة، الخروج من وضع
  الشاشة الكاملة، محاولات النسخ/اللصق، القائمة المنسدلة (الزر الأيمن)،
  اختصارات لوحة المفاتيح الشائعة لأدوات المطور، واشتباه بفتح أدوات المطور.
- إنهاء الامتحان تلقائياً بعد تجاوز عدد مخالفات يحدده الأستاذ لكل امتحان.
- ترتيب عشوائي للأسئلة والخيارات يختلف من طالب لآخر.
- توقيت مفروض من الخادم — لا يمكن تمديد الوقت بإغلاق الصفحة أو تعديل
  ساعة الجهاز؛ الخادم يتحقق من الموعد النهائي في كل طلب.
- منع استخدام نفس رمز الامتحان من جهازين في نفس الوقت.
- حفظ تلقائي للإجابات أثناء الحل.

**للأستاذ:**
- إنشاء حساب وتسجيل دخول آمن (كلمات مرور مُشفّرة).
- إنشاء امتحانات وتعديل إعداداتها (المدة، حد المخالفات، تفعيل العشوائية).
- إضافة/تعديل/حذف الأسئلة: اختيار من متعدد، صح/خطأ، إجابة قصيرة.
- توليد رموز دخول بالجملة أو بأسماء طلاب محددة، مع نسخ سريع.
- عرض النتائج والدرجات لكل طالب، وتصحيح الأسئلة المقالية يدوياً.
- عرض سجل المخالفات الكامل لكل محاولة (نوع المخالفة والوقت).

## تنبيه مهم حول منع الغش

لا يوجد نظام امتحانات أونلاين يمنع الغش 100% دون استخدام كاميرا ومراقبة
بشرية أو بالذكاء الاصطناعي. هذا النظام يطبّق كل طبقات الحماية الممكنة عبر
المتصفح والخادم (المذكورة أعلاه)، وهي فعّالة ضد الغش العرضي وتسجّل أي
محاولة للأستاذ ليراجعها — لكنها لا تمنع طالباً مصمماً على استخدام جهاز
ثانٍ منفصل تماماً عن المتصفح.

## التقنيات

- [Next.js 16](https://nextjs.org) (App Router) + TypeScript + Tailwind CSS 4
- [Prisma](https://www.prisma.io) + PostgreSQL
- مصادقة الأستاذ عبر JWT (`jose`) في كوكي httpOnly، وكلمات مرور مُشفّرة بـ `bcryptjs`
- التحقق من المدخلات بـ `zod`

## الإعداد المحلي

### المتطلبات
- Node.js 20+
- قاعدة بيانات PostgreSQL (محلية أو سحابية)

### الخطوات

```bash
npm install

cp .env.example .env
# عدّل DATABASE_URL و AUTH_SECRET في .env

npx prisma migrate dev --name init

# اختياري: بيانات تجريبية (أستاذ + امتحان + رموز دخول)
npm run db:seed

npm run dev
```

يفتح الموقع على http://localhost:3000

بيانات الدخول التجريبية بعد `npm run db:seed`:
- البريد: `teacher@example.com`
- كلمة المرور: `password123`

### أوامر مفيدة

| الأمر | الوصف |
|---|---|
| `npm run dev` | تشغيل بيئة التطوير |
| `npm run build` | بناء نسخة الإنتاج |
| `npm run lint` | فحص الكود |
| `npm run db:migrate` | إنشاء/تطبيق migration جديدة |
| `npm run db:studio` | فتح Prisma Studio لتصفح قاعدة البيانات |
| `npm run db:seed` | تعبئة بيانات تجريبية |

## النشر (Deployment)

1. استضف قاعدة بيانات PostgreSQL (مثل Neon، Supabase، Railway، أو RDS).
2. اضبط متغيرات البيئة `DATABASE_URL` و `AUTH_SECRET` (قيمة عشوائية طويلة
   وليست القيمة الافتراضية) على منصة الاستضافة (مثل Vercel).
3. شغّل `npx prisma migrate deploy` عند النشر لتطبيق الـ migrations.
4. انشر التطبيق (مثلاً عبر Vercel، فهو يدعم Next.js مباشرة).

```
src/app/api/exam/...        واجهات API الخاصة بالطالب أثناء الامتحان
src/app/teacher/...         صفحات لوحة تحكم الأستاذ
src/app/exam/...            صفحات دخول الطالب وحل الامتحان
src/components/             مكوّنات واجهة قابلة لإعادة الاستخدام + hook منع الغش
```
